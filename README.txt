LIBVAULT - LIBRARY MANAGEMENT SYSTEM
=====================================
Java Servlets + JSP + JDBC + MySQL (no frameworks, pure Java EE - runs directly in Eclipse)
Now with: hashed passwords, real email notifications, and a redesigned professional UI.

--------------------------------------------------
STEP 1: INSTALL REQUIREMENTS
--------------------------------------------------
1. Eclipse IDE for Enterprise Java Developers (has Dynamic Web Project support)
2. Apache Tomcat 9 (download from tomcat.apache.org, this project uses javax.servlet
   which matches Tomcat 9. If you use Tomcat 10+, you must change every
   "javax.servlet" import to "jakarta.servlet" in the 4 servlet files, and
   "javax.mail" to "jakarta.mail" in MailUtil.java.)
3. MySQL Server + MySQL Workbench (or just the MySQL command line)
4. Two jar files, both go in WebContent/WEB-INF/lib/:
     a) MySQL Connector/J - "mysql-connector-j-8.x.x.jar"
        https://dev.mysql.com/downloads/connector/j/
     b) JavaMail - "javax.mail-1.6.2.jar" (needed for the email notification
        feature - contact form + borrow/return emails). Get it from Maven Central:
        https://mvnrepository.com/artifact/com.sun.mail/javax.mail/1.6.2
        (download the jar directly, or add as a Maven dependency if your
        project uses Maven)

--------------------------------------------------
STEP 2: CREATE THE DATABASE
--------------------------------------------------
Open MySQL Workbench (or CLI) and run the file: database/libvault.sql
This creates the "libvault" database, all 3 tables, an admin account and 5 sample books.
Passwords are stored as salted SHA-256 hashes (see PasswordUtil.java) - the seeded
admin row already contains a correctly hashed password, no extra step needed.

Default admin login:
  Email:    admin@libvault.com
  Password: admin123

If you already created the database using an OLDER version of this project
(plain-text passwords), just run this one line instead of the whole script:
  ALTER TABLE users MODIFY password VARCHAR(255) NOT NULL;
Existing accounts will keep working - old plaintext passwords are automatically
upgraded to hashed ones the next time that user logs in.

--------------------------------------------------
STEP 3: CREATE THE ECLIPSE PROJECT
--------------------------------------------------
1. Eclipse > File > New > Dynamic Web Project
2. Project name: LibVault
3. Target runtime: Apache Tomcat v9.0 (set this up first via Window > Preferences >
   Server > Runtime Environments if not already added)
4. Dynamic web module version: 4.0
5. Click "Generate web.xml deployment descriptor" -> Finish

Copy the contents of this zip's WebContent/ and src/ folders straight into your
Eclipse project (same folder names), or just import this zip as an existing project.

--------------------------------------------------
STEP 4: WHERE EACH FILE GOES (if pasting manually)
--------------------------------------------------
FOLDER: src/com/libvault/util/
  - DBConnection.java   (MySQL connection settings)
  - FineUtil.java        (fine calculation)
  - PasswordUtil.java     (password hashing)
  - MailUtil.java          (sends emails via Gmail SMTP)

FOLDER: src/com/libvault/model/
  - User.java, Book.java, Transaction.java

FOLDER: src/com/libvault/dao/
  - UserDAO.java, BookDAO.java, TransactionDAO.java

FOLDER: src/com/libvault/servlet/
  - AuthServlet.java     (register/login/logout/profile)
  - BookServlet.java      (browse/search/borrow/return/history)
  - AdminServlet.java      (dashboard/CRUD/users/issue/renew/fines)
  - ContactServlet.java     (sends the Contact page message by email)

FOLDER: WebContent/ (project root web folder)
  - index.jsp, register.jsp, login.jsp, profile.jsp, books.jsp,
    bookdetails.jsp, myborrowed.jsp, history.jsp, about.jsp, contact.jsp,
    header.jsp, footer.jsp

FOLDER: WebContent/admin/
  - dashboard.jsp, books.jsp, addbook.jsp, editbook.jsp, users.jsp,
    issuebook.jsp, transactions.jsp, fines.jsp

FOLDER: WebContent/css/
  - style.css   (the whole visual design system lives here)

FOLDER: WebContent/WEB-INF/
  - web.xml (already generated by Eclipse - replace with the one provided)

FOLDER: WebContent/WEB-INF/lib/
  - mysql-connector-j-8.x.x.jar
  - javax.mail-1.6.2.jar

--------------------------------------------------
STEP 5: CONFIGURE THE DATABASE
--------------------------------------------------
Open: src/com/libvault/util/DBConnection.java
Change USER and PASSWORD to match your local MySQL credentials.

--------------------------------------------------
STEP 6: CONFIGURE EMAIL (OPTIONAL BUT RECOMMENDED)
--------------------------------------------------
Open: src/com/libvault/util/MailUtil.java

1. Use a Gmail account (or edit HOST/PORT for another provider).
2. Turn on 2-Step Verification on that Gmail account.
3. Go to https://myaccount.google.com/apppasswords and generate an "App Password"
   (16 characters, no spaces).
4. Fill in:
     USERNAME       = your Gmail address
     APP_PASSWORD   = the 16-character app password (NOT your normal Gmail password)
     ADMIN_EMAIL    = where you want Contact-page messages delivered

If you skip this step, the app still works completely fine - email sending just
fails silently in the server console log ("LibVault mail send failed...") and
borrowing/returning/contact submissions are unaffected. Set ENABLED = false in
MailUtil.java to turn off email attempts entirely.

--------------------------------------------------
STEP 7: RUN IT
--------------------------------------------------
Right-click the project > Run As > Run on Server > choose your Tomcat 9 server > Finish.
Eclipse opens an embedded browser at something like:
  http://localhost:8080/LibVault/

Copy that same URL into Chrome/Edge and it works identically.

--------------------------------------------------
STEP 8: MAKE IT PUBLICLY SHAREABLE (ANYONE CAN OPEN THE LINK)
--------------------------------------------------
"localhost" only works on your own PC. To let anyone in the world open your link:

OPTION A - Quick demo link (temporary, good for showing friends/instructor):
  1. Download ngrok (ngrok.com) and sign up (free).
  2. With Tomcat running on port 8080, open a terminal and run:
        ngrok http 8080
  3. ngrok gives you a public URL like https://random-name.ngrok-free.app
  4. Share that link -> anyone can open https://random-name.ngrok-free.app/LibVault/
  Note: this link stops working once you close ngrok/Eclipse; it's for demos only.

OPTION B - Real permanent hosting (for a project that stays online):
  Deploy the built .war file to a cloud host that supports Java/Tomcat + MySQL
  (Render, Railway, a small VPS with Tomcat + MySQL installed, or a shared Java
  host). Export the project as a WAR (right-click project > Export > WAR file)
  and point DBConnection.java at your cloud MySQL instance's host/user/password
  before exporting.

--------------------------------------------------
WHAT'S NEW IN THIS VERSION
--------------------------------------------------
1. SECURITY - passwords are now salted SHA-256 hashes (PasswordUtil.java), not
   plaintext. Old plaintext accounts auto-upgrade to hashed on their next login.

2. EMAIL NOTIFICATIONS - real emails now go out for:
   - Borrowing a book (confirmation + due date + fine warning)
   - Returning a book (confirmation + fine amount if late)
   - Contact page submissions (delivered straight to your inbox)
   All sent via MailUtil.java over Gmail SMTP (see Step 6).

3. VISUAL REDESIGN - a full professional design system in style.css:
   - Warm library palette (deep navy + gold accents on cream background)
   - Custom serif display font (Fraunces) for headings, Inter for body text
   - Redesigned hero section on the home page with a CSS-drawn bookshelf
   - Split-panel login/register screens with a photographic side panel
   - Polished admin "ledger" dashboard, elevated book cards, refined tables,
     badges, buttons and forms throughout
   - Fully responsive (mobile, tablet, desktop) via Bootstrap 5 grid

--------------------------------------------------
FEATURES INCLUDED (FULL LIST)
--------------------------------------------------
User side: home page, register, login/logout, profile edit, search/filter books,
book details, availability check, borrow, return, my borrowed books, borrowing
history, due dates, automatic fine calculation (Rs 5/day late), email
notifications, success/error banner messages.

Admin side: admin login (same login form, role based redirect), dashboard with
live stats (total/available/issued books, total members, overdue count, total
fines), add/edit/delete books, search books, manage members (block/unblock),
issue book to any member, return/renew any transaction, full transaction
history, fine management (mark as paid).

Extra: About page, Contact page (with real email delivery), responsive design,
HTML5 form validation, role-based access (USER vs ADMIN session checks on
every admin page), MySQL-backed persistence throughout, hashed passwords.
